# 📌 Progetto My Hero Academia RPG

Un videogioco di ruolo a turni basato sull'universo di 'My Hero Academia':
Il software è un RPG tattico che sfida il giocatore a scalare i piani di una torre presidiata da temibili Villain.
---

## 🚀 Come eseguire il progetto

### Prerequisiti
- Java 25 (LTS)
- Gradle

### Istruzioni

```bash
git clone <https://github.com/denisfrumusache-cyber/ProgettoMDP>
cd <ProgettoMHA>
```

### Build del progetto
```bash
./gradlew build
```

### Esecuzione
```bash
./gradlew run
```
